# Fundoo App (Express.js)

Fundoo App is a backend service built with **Express.js** that allows users to register and log in. It securely hashes passwords using **bcrypt** before storing them in the database.

## Features

- **User Registration** with name, email, phone number, and password.
- **Password Hashing** using bcrypt before saving to the database.
- **User Login** with email and password authentication.
- **JWT Token Generation** for authentication.

## Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB**
- **Mongoose**
- **bcrypt**
- **jsonwebtoken (JWT)**
